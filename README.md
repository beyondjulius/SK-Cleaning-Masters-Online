# SK International Cleaning Masters — website starter

## Pages
- index.html — Home
- services.html — full service architecture
- industries.html — sectors / property types
- work.html — evidence-led portfolio
- about.html — brand / operating philosophy
- contact.html — general enquiry
- quote.html — customer-intent quote form
- privacy.html / terms.html — legal placeholders

## Before launch
1. Replace the placeholder SVG artwork with real SK photography.
2. Confirm the legal business name, trading name, service area, phone, email, WhatsApp and physical address.
3. Connect contact/quote forms to the actual email, CRM or WhatsApp workflow.
4. Replace all placeholder legal text with reviewed policies.
5. Replace `example.com` in sitemap/canonical/schema with the real domain.
6. Add only verified testimonials, credentials, reviews, project results and business statistics.
7. Validate structured data and sitemap in Google Search Console / Rich Results Test.
8. Run Lighthouse/PageSpeed and accessibility testing on the deployed site.

## Design/technical intent
The site uses semantic HTML, responsive CSS, keyboard-visible focus, reduced-motion support, restrained motion, accessible form labels, page-specific metadata, and a customer-intent information architecture. It intentionally avoids invented proof points.
